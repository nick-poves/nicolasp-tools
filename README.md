# NicolasP Tools [J A N]

**Userscript para Bubble.am — Green Neon Edition**

Fast Feed · Movimiento WASD · Skin personalizada · Ocultar nick

---

## Instalación

1. Instala la extensión [Tampermonkey](https://www.tampermonkey.net/) en tu navegador.
2. Haz clic en el botón:

### [▶ INSTALAR NICOLASP TOOLS](https://raw.githubusercontent.com/nick-poves/nicolasp-tools/main/nicolasp-tools.user.js)

3. En la ventana de Tampermonkey pulsa **Instalar**.
4. Entra a [bubble.am](https://bubble.am) y presiona **ESC** para abrir el panel.

Las actualizaciones se instalan automáticamente.

## Funciones

| Función | Descripción |
|---|---|
| Fast Feed | Alimentación rápida manteniendo una tecla (por defecto `E`), intervalo de 10 a 150 ms |
| WASD | Control de dirección con el teclado, incluye diagonales |
| Skin personalizada | Usa una imagen propia como skin |
| Ocultar nick | Oculta el nombre sobre tus células |

## Controles

| Tecla | Acción |
|---|---|
| `ESC` | Mostrar / ocultar panel |
| `E` | Fast Feed (configurable) |
| `W` `A` `S` `D` | Movimiento |
